# Ocean Side Derma

Astro + React islands + Tailwind CSS + Framer Motion.

## Commands
- `npm run dev` — start local server at http://localhost:4321
- `npm run build` — build the site into `dist/`
- `npm run preview` — preview the built site

## Folders
- `src/pages` — each file is a page (URL)
- `src/layouts` — page shells (head, header, footer)
- `src/components` — static Astro components (no JS sent to browser)
- `src/islands` — interactive React components (use with `client:*`)
- `src/data` — site content and settings (name, nav, services)
- `src/styles` — global CSS and Tailwind theme colors/fonts
- `public/images` — images served as-is
